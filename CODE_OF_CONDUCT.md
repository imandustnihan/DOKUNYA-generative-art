# Community code of conduct

Treat contributors and users with respect. Discuss ideas and code with concrete evidence. Welcome different levels of experience. Harassment, threats, discriminatory abuse, doxxing and publication of private information are not acceptable.

Maintainers may edit or remove harmful content, pause a conversation or restrict participation. Apply these rules consistently and explain moderation decisions without exposing private information. Report concerns privately through an available repository maintainer contact; do not publish someone else's private details in an issue.
