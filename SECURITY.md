# Security and privacy

RENIZ 0.1.x is the initial supported development line. It has no accounts, backend, advertising or analytics. Project import is restricted to versioned JSON with a 4 MiB limit, bounded nesting/counts and numeric validation. Never place tokens, signing keys or personal artwork in a public issue.

For a vulnerability, use the repository's private vulnerability reporting feature if the owner has enabled it. Otherwise open an issue containing only a non-sensitive high-level description and ask for a private channel before sharing exploit details. No unverified contact address is provided here.

A successful licence review and passing tests do not establish that dependencies are free of vulnerabilities. Dependabot is configured for Dart and Actions. Export JSON backups for work you need to retain: browser storage can be cleared by the browser/user, and disk operations can fail.
