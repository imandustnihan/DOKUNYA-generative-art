# Changelog

## 0.1.0 — 2026-11-19

- Five interactive art engines, ten presets and six palettes.
- Adaptive compact, tablet and desktop studio; experimental TV/ambient interface.
- Touch/stylus/mouse drawing, multi-touch zoom, wheel panning and keyboard actions.
- Actual particle budgets, frame-timing-driven Auto quality, pause and reduced motion.
- Versioned editable JSON projects, local gallery and bounded imports.
- Native project-file storage with recovery and transactional browser IndexedDB.
- Artwork-only PNG export, mobile share sheets and desktop file dialogs.
- English, Turkish and Azerbaijani interfaces.
- Optional GLSL liquid field and complete Canvas fallback.
- Pinned Flutter SDK, tests, build workflows and documented platform evidence.
